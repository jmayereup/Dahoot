Dahoot Bulk Import Guide

JSON format reference for bulk quiz question import

💡 Pro-Tip: Copy the system instructions at the bottom of this page and paste them into ChatGPT, Claude, or Google Gemini to generate flawless custom quiz questions in JSON format instantly!

JSON Format

Import questions as a JSON array. Each object must have type, text, and options fields. The supported types are MULTIPLE_CHOICE, SORTING, DRAG_DROP, DROP_DOWN, CATEGORIZE, and DISCUSSION.

1. Multiple Choice (MULTIPLE_CHOICE)

  • text: The question prompt.
  • options.correct_answer: The correct answer string.
  • options.distractors: Array of 3 incorrect options.
{
  "type": "MULTIPLE_CHOICE",
  "text": "Which programming language was created by Brendan Eich?",
  "options": {
    "correct_answer": "JavaScript",
    "distractors": ["Java", "Python", "C++"]
  }
}

2. Sorting Order (SORTING)

  • text: Sorting instruction.
  • options.correct_sequence: Array of 4 items in the correct order (first to last).
{
  "type": "SORTING",
  "text": "Sort these tech stack layers from front-end to back-end.",
  "options": {
    "correct_sequence": [
      "HTML / CSS UI Layout",
      "React State Management",
      "Express Server Router",
      "Database Storage"
    ]
  }
}

3. Drag & Drop Blanks (DRAG_DROP)

  • options.sentence: Sentence with [blank0], [blank1] placeholders.
  • options.answers_in_order: Correct words for each blank, in order.
  • options.distractors: Wrong words to mix in as decoys.
{
  "type": "DRAG_DROP",
  "text": "Complete the sentence about React hooks.",
  "options": {
    "sentence": "In React, we use the [blank0] hook to manage state, and [blank1] to perform side effects.",
    "answers_in_order": ["useState", "useEffect"],
    "distractors": ["useContext", "useRef"]
  }
}

4. Drop-Down Choices (DROP_DOWN)

  • options.sentence: Sentence with {{0}}, {{1}} placeholders.
  • options.dropdowns: Array of objects, one per placeholder.
  • Each dropdown: correct_answer + distractors array.
{
  "type": "DROP_DOWN",
  "text": "Fill in the blanks about PocketBase.",
  "options": {
    "sentence": "PocketBase is written in {{0}} and uses {{1}} as its database.",
    "dropdowns": [
      {
        "correct_answer": "Go",
        "distractors": ["Rust", "JavaScript"]
      },
      {
        "correct_answer": "SQLite",
        "distractors": ["PostgreSQL", "MongoDB"]
      }
    ]
  }
}

5. Categorize Items (CATEGORIZE)

  • options.categories: Array of category names.
  • options.items: Array of { name, category } objects mapping each item to a category.
{
  "type": "CATEGORIZE",
  "text": "Classify the following tech elements.",
  "options": {
    "categories": ["Languages", "Frameworks"],
    "items": [
      { "name": "JavaScript", "category": "Languages" },
      { "name": "React", "category": "Frameworks" },
      { "name": "Python", "category": "Languages" },
      { "name": "Next.js", "category": "Frameworks" }
    ]
  }
}

6. Discussion Prompts (DISCUSSION)

  • text: The discussion question or debate prompt.
  • options.placeholder: Placeholder text shown inside student input box.
  • options.sample_answers: Array of reference or guide discussion points.
  • options.max_length: Maximum answer character length (default 250).
{
  "type": "DISCUSSION",
  "text": "Why do you think learning a second language is beneficial in today's world?",
  "options": {
    "placeholder": "Share your thoughts...",
    "sample_answers": ["Global career opportunities", "Cultural appreciation", "Cognitive benefits"],
    "max_length": 250
  }
}

Complete Import Example

Paste a JSON array like this into the import textarea: 

[
  {
    "type": "MULTIPLE_CHOICE",
    "text": "What is the capital of France?",
    "options": {
      "correct_answer": "Paris",
      "distractors": ["Berlin", "London", "Rome"]
    }
  },
  {
    "type": "SORTING",
    "text": "Sort these numbers from lowest to highest.",
    "options": {
      "correct_sequence": ["Five", "Ten", "Fifteen", "Twenty"]
    }
  }
]

AI Prompt Template

💎 Pre-configured Gemini Gem: Use the Dahoot Quiz Generator Gem to generate questions directly in JSON format — no setup needed.
💡 Manual prompt: Copy the prompt below and use it with ChatGPT, Claude, Gemini, or any LLM to generate questions as a JSON array ready for import. 
You are a quiz question generator. Output ONLY a raw JSON array matching the schemas below, with no conversational text, no markdown codeblocks, no wrapping.

Generate questions for: [SPECIFY SUBJECT, LANGUAGE LEVEL, AND TOPIC HERE]

Question type schemas:

1. MULTIPLE_CHOICE:
{
  "type": "MULTIPLE_CHOICE",
  "text": "Question prompt",
  "options": {
    "correct_answer": "Correct option",
    "distractors": ["Wrong 1", "Wrong 2", "Wrong 3"]
  }
}

2. SORTING:
{
  "type": "SORTING",
  "text": "Sorting instruction",
  "options": {
    "correct_sequence": ["Item 1 (first)", "Item 2", "Item 3", "Item 4 (last)"]
  }
}

3. DRAG_DROP:
{
  "type": "DRAG_DROP",
  "text": "Instruction text",
  "options": {
    "sentence": "Sentence with [blank0] and [blank1].",
    "answers_in_order": ["word1", "word2"],
    "distractors": ["decoy1", "decoy2"]
  }
}

4. DROP_DOWN:
{
  "type": "DROP_DOWN",
  "text": "Instruction text",
  "options": {
    "sentence": "Sentence with {{0}} and {{1}}.",
    "dropdowns": [
      { "correct_answer": "answer1", "distractors": ["wrong1", "wrong2"] },
      { "correct_answer": "answer2", "distractors": ["wrong1", "wrong2"] }
    ]
  }
}

5. CATEGORIZE:
{
  "type": "CATEGORIZE",
  "text": "Instruction text",
  "options": {
    "categories": ["Category A", "Category B"],
    "items": [
      { "name": "Item 1", "category": "Category A" },
      { "name": "Item 2", "category": "Category B" }
    ]
  }
}

6. DISCUSSION:
{
  "type": "DISCUSSION",
  "text": "Discussion prompt or open-ended question",
  "options": {
    "placeholder": "Type your answer...",
    "sample_answers": ["Sample point 1", "Sample point 2"],
    "max_length": 250
  }
}

Return ONLY a valid JSON array of question objects. No other text.
