Dahoot Bulk Import Guide

Quick reference formatting rules for bulk quiz question generation

💡 Pro-Tip: Copy the system instructions at the bottom of this page and paste them directly into ChatGPT, Claude, or Google Gemini to generate flawless custom quiz questions instantly!

Question Formats

Each question block must begin with its corresponding type header (e.g. # MULTIPLE_CHOICE), followed by the question text prompt, then configuration options/lines.

1. Multiple Choice (# MULTIPLE_CHOICE)

  • Provide a question prompt.
  • List 4 answer choices using bullet points (starting with -).
  • Prefix the correct option with an asterisk: - *Correct Option.
# MULTIPLE_CHOICE
Which programming language was created by Brendan Eich in 1995?
- Java
- *JavaScript
- Python
- C++

2. Sorting Order (# SORTING)

  • Provide a sorting prompt.
  • List 4 items in their correct sorted order using numbered points: 1., 2., etc.
  • Dahoot shuffles the elements automatically during the game.
# SORTING
Sort these tech stack layers from front-end to back-end.
1. HTML / CSS UI Layout
2. React State Management
3. Express Server Router
4. Database Storage

3. Drag & Drop Blanks (# DRAG_DROP)

  • Provide a prompt.
  • Use Sentence: followed by a sentence containing placeholders like [blank0] and [blank1].
  • List 4 bullet point choices. Prefixes correct choices in correct blank order with *. Other choices act as distractors.
# DRAG_DROP
Complete the sentence about React hooks.
Sentence: In React, we use the [blank0] hook to manage state, and [blank1] to perform side effects.
- *useState
- *useEffect
- useContext
- useRef

4. Drop-Down Choices (# DROP_DOWN)

  • Provide a prompt.
  • Use Sentence: followed by a sentence containing placeholders like {{0}} and {{1}}.
  • List dropdown options under a Dropdown N: header. Correct answer must be prefixed with *.
# DROP_DOWN
Fill in the blanks regarding PocketBase architecture.
Sentence: PocketBase is written in {{0}} and uses {{1}} as its default database engine.
Dropdown 0:
- *Go
- Rust
- JavaScript
Dropdown 1:
- *SQLite
- PostgreSQL
- MongoDB

5. Categorize Items (# CATEGORIZE)

  • Provide a classification prompt.
  • Provide category names with Categories: CategoryA, CategoryB.
  • List mapped items under Items: with the format - Item Name: Category Name.
# CATEGORIZE
Classify the following tech elements.
Categories: Languages, Frameworks
Items:
- JavaScript: Languages
- React: Frameworks
- Python: Languages
- Next.js: Frameworks

Gemini Gem / Custom GPT System Instructions

Paste the following prompt instructions into your Custom AI chatbot settings to configure it: 

You are the Dahoot Quiz Generator. Output ONLY raw Markdown questions matching the formats described below, with no conversational text:

# MULTIPLE_CHOICE
Question prompt here
- Incorrect Option 1
- *Correct Option (starts with - *)
- Incorrect Option 2
- Incorrect Option 3

# SORTING
Question prompt here
1. First Item (Correct Order)
2. Second Item (Correct Order)
3. Third Item (Correct Order)
4. Fourth Item (Correct Order)

# DRAG_DROP
Question prompt here
Sentence: Sentence goes here with placeholders like [blank0] and [blank1].
- *Correct Choice for [blank0] (starts with - *)
- *Correct Choice for [blank1] (starts with - *)
- Distractor Choice 1
- Distractor Choice 2

# DROP_DOWN
Question prompt here
Sentence: Sentence goes here with dropdown slots like {{0}} and {{1}}.
Dropdown 0:
- *Correct Choice (starts with - *)
- Option 2
- Option 3
Dropdown 1:
- *Correct Choice (starts with - *)
- Option 2
- Option 3

# CATEGORIZE
Question prompt here
Categories: CategoryA, CategoryB
Items:
- Item 1: CategoryA
- Item 2: CategoryB
- Item 3: CategoryA
- Item 4: CategoryB
